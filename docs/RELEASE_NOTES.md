# Remover 0.4.0

Manage followers in Chrome with live Keeping, Planned removal, Needs a check, Removal queue, and Removed views. Search profiles, inspect evidence, mark Keep exceptions, and control processing settings. Loading followers and checking activity do not approve removal. Start cleanup requires confirmation for the current account.

The advanced terminal inventory is back: use `remover --advanced` or Tab before a job. Background mode restores the continuous ladle/X animation, confirmed-removal tags, and pause/cooldown state. Press v to switch to the work list.

Both interfaces share the existing local controller, saved queue, rules, and account protections. Reload the R extension after updating.

The standard activity check now uses the latest visible post date. It stops after finding a date instead of walking separate replies and reposts timelines. Saved old dates can leave the activity retry queue without another read. Failed removal budgets and X cooldowns remain enforced.
