# Remover 0.4.1

The manager now opens directly to the follower table. Removed slogans, large headings, duplicate summary cards, and repeated explanations. Account status and actions stay at the top; job progress appears only when work exists.

When installed files are newer than the running Chrome extension, the page shows a Reload extension button instead of an unavailable-worker error. Reload does not start cleanup. Follower rules and queue behavior are unchanged.
