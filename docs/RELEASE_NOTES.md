A small, local follower cleaner controlled from a Ratatui terminal UI, with Chrome handling X requests.

- One-command authenticated installation for Apple Silicon macOS; no sudo or build tools.
- Checksum verification, repeatable updates, stable unpacked-extension path, and uninstall that preserves cleanup data.
- Follower scans, strict default cleanup filters, keep list, reviewed removal batches, pause/resume and uncertain-outcome recovery.
- Ladle-pouring-on-X animation with verified removal counter and a reduced-motion option.

Use the installation command in the README. You need GitHub CLI authentication with access to this private repository, then one manual Chrome Load unpacked step and pairing.

Live X endpoint compatibility remains unverified. No real follower removal was used to validate this release. The terminal demo, automated checks, and installer tests use local/synthetic data.
