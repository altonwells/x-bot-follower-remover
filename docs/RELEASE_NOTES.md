# Remover 0.4.4

Increases the fly artwork from 2,800 to 15,500 sampled points. A wider silhouette, segmented abdomen, compound-eye texture, wing veins, leg bristles, and shaded visible surfaces improve detail at normal terminal sizes.

This release changes the fly illustration only. The brain remains an explicitly labeled visualization, not live neural simulation. Cleanup behavior and the Chrome driver are unchanged.
